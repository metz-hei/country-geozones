# Упрощённые геозоны стран и областей

В этом репозитории хранятся **упрощённые геозоны стран и областей** с **выровненной геометрией**.

Часть стран представлена **на уровне административных единиц** (области/штаты/провинции), а часть — **единым контуром страны**.

## Пример описания геозоны области

```json
"properties": {
  "name": "Альберта",
  "name_original": "Alberta",
  "country": "Канада",
  "country_code": "ca",
  "region_code": "CA-AB",
  "address": {
    "ISO3166-2-lvl4": "CA-AB"
  }
},
"id": "CA-AB"
```

## Пример описания геозоны страны

```json
"properties": {
  "cca2": "ni"
}
```
